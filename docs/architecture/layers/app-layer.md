# Стандарт слоя `app` (FSD)

Область действия: `src/app/`. Стандарт основан на FSD 2.1 с осознанными отступлениями, помеченными как **[исключение из FSD]**.

---

## 1. Назначение слоя

`app` — точка входа приложения: инициализация React, глобальные провайдеры, роутинг. Самый верхний слой FSD — импортирует из всех нижележащих, в него не импортирует никто.

---

## 2. Структура слоя

```
src/app/
├── main.tsx           # ReactDOM.createRoot, точка входа
├── App.tsx            # Глобальные провайдеры
├── index.css           # Глобальные стили
└── route/
    ├── route.tsx        # Конфигурация роутера
    ├── loaders.ts        # Лоадеры маршрутов
    └── index.ts          # Public API сегмента
```

---

## 3. Точка входа

### 3.1. `main.tsx`

Единственная точка рендера в DOM: `ReactDOM.createRoot(...).render(<App />)`, обёрнутая в `StrictMode`. Ничего, кроме монтирования корневого компонента, здесь не происходит.

### 3.2. `App.tsx`

Собирает глобальные провайдеры слоем — каждый следующий оборачивает предыдущий:

```
QueryClientProvider     // TanStack Query, клиент из shared/api
└── HotkeyProvider       // core/hotkeys
    └── RouterProvider    // router из app/route
```

Условно подключаемые инструменты (например, `ReactQueryDevtools`) включаются по `envConfig.env` (`shared/config`) и не влияют на структуру дерева провайдеров.

---

## 4. Сегмент `route`

Отвечает за конфигурацию маршрутов и их защиту.

- **`route.tsx`** — дерево маршрутов (`createBrowserRouter`). Каждая страница подключается лениво через `lazy: async () => ({ Component: (await import("@/pages/{page}")).{Page}Page })` — код-сплиттинг по страницам обязателен. Импорт страницы — только через её public API (`@/pages/{page}`), без обращения к внутренним файлам.
- **`loaders.ts`** — лоадеры маршрутов (`authLoader`, `guestLoader` и т.п.), реализующие защиту доступа (редирект неавторизованных / уже авторизованных пользователей). Работают через сторы `core` (например, `useSessionStore` из `core/auth`).
- **`index.ts`** — public API сегмента, отдаёт наружу только `router`.
