# Формат файла импорта сообщений WebSocket

Файл `websocket-example-import.json` — пример JSON-файла для импорта примеров сообщений (example frames) в WebSocket-доку Docpoint.

## Точки входа

**Импорт сокета целиком** — кнопка «↓ Импортировать» в блоке «Прикреплённые WebSocket» на странице домена (`DomainShowPage`). Создаёт новый сокет из блока `websocket` (имя, адрес, описание), прикрепляет его к домену и заливает в него все `messages`. Здесь блок `websocket` **обязателен**, а `messages` можно опустить — получится пустой сокет.

**Импорт сообщений в открытый сокет** — добавляет `messages` в сокет, открытый на странице `DocWsShowPage`; блок `websocket` в этом случае справочный. Мутация есть в `useWebsocketMessages` (`importMessagesAsync`), кнопки в интерфейсе пока нет.

## Общая структура

```json
{
  "version": 1,
  "websocket": { ... },   // необязательно, справочная информация
  "messages": [ ... ]     // обязательно, список сообщений для импорта
}
```

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `version` | number | да | Версия формата файла (сейчас всегда `1`) |
| `websocket` | object | зависит | Описание сокета. Обязателен при импорте в домен — из него создаётся сокет. При импорте в уже открытый сокет справочный и не используется |
| `messages` | Message[] | зависит | Список импортируемых сообщений. Обязателен и непуст при импорте в открытый сокет; при импорте в домен можно опустить |

---

## `websocket` — описание сокета

```json
"websocket": {
  "name": "Kline Stream",
  "url": "wss://example.com/ws",
  "desc": "Стрим свечей биржи"
}
```

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | string | Название сокета. Обязательно при импорте в домен, иначе справочное |
| `url` | string | URL сокета. Обязателен при импорте в домен, иначе справочный |
| `desc` | string | Описание сокета. По умолчанию — пустая строка |

---

## `messages` — список сообщений

Каждый элемент — одно сохранённое сообщение-пример, повторяет форму `CreateWebsocketMessageDTO` без `websocket_id` (он подставляется автоматически на месте импорта).

```json
{
  "name": "Subscribe",
  "desc": "Подписка на kline-стрим",
  "payload": "{ \"op\": \"subscribe\", \"id\": \"init\", \"streams\": \"kline.exchange.symbol.interval\" }"
}
```

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `name` | string | да | Название сообщения, отображается в сайдбаре «Examples» |
| `desc` | string | нет | Описание назначения сообщения. По умолчанию — пустая строка |
| `payload` | string | да | Тело сообщения. Хранится и передаётся как строка — JSON внутри экранируется (`\"`, `\n`), как в примере выше |

---

## Чек-лист перед импортом

- [ ] JSON валиден (используйте линтер или `jq .`)
- [ ] `version` равен `1`
- [ ] У каждого сообщения есть `name` и `payload`
- [ ] `payload` — это **строка**, а не объект. JSON внутри экранирован
- [ ] Для импорта в домен: заполнены `websocket.name` и `websocket.url`
- [ ] Для импорта в открытый сокет: `messages` непуст, а на странице WebSocket открыт нужный сокет

## Минимальный шаблон

```json
{
  "version": 1,
  "messages": [
    {
      "name": "Ping",
      "desc": "",
      "payload": "{ \"op\": \"ping\" }"
    }
  ]
}
```

Полный пример доступен в [websocket-example-import.json](websocket-example-import.json).
